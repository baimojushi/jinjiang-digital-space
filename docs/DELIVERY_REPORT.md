# 交付变更报告

## 适配结果

本次修改以业务数字资产和 MVP 开发方案为基础，将原硬编码模拟作品数据迁移为数据库驱动的真实资产服务。

### 1. 用户端

- 原每日推荐接口保持兼容
- 推荐数据源切换为真实公开资产视图
- 推荐标签显示真实业务资产编号
- 推荐来源显示作者、来源和授权状态
- 用户喜欢、收藏、换一件、加入策展继续写入行为数据库
- 预留 `space_id`，只有审核通过并允许展陈的 Space 才能提交具体空间选择

### 2. 推荐服务

推荐链路：

```text
CultureAsset 全量资产
→ 发布门禁
→ 酒店/主题匹配
→ Top-N
→ 带权随机
→ 用户反馈回流
```

当前 46 条文化资产中有 10 条进入公开推荐池。

### 3. 酒店端

原运营看板保留。

新增数字资产管理后台，支持：

- 资产查询
- 授权状态维护
- 审核状态维护
- 发布状态维护
- 发布门禁检查
- 数据质量问题定位
- Space 字段补录
- 媒体资产查看
- 数据导入批次查看
- 空间匹配重算
